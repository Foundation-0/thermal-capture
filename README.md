# thermal-capture

Research on contained thermal systems.

This project asks whether heat in ordinary air can be turned into electricity, and tests each route against measured numbers.

It holds the question record, the findings so far, and the research work that follows from them.

## Contents

- INQUISITION.md: the founding questions, word for word, in the order they were asked.
- DIRECTION.md: what the questions narrowed to, what is established, the open routes, and the test programme.

## Related project

[ductricity](https://github.com/Foundation-0/ductricity) is a separate project that came out of question 4 in the inquisition record. It covers one device idea: a duct where the same surface shapes the flow and extracts energy from it.

## Status

Research direction only. No device has been built under this project. No result is claimed beyond the published work cited in DIRECTION.md.
